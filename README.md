# Java_Student_Management-2026

这是我大二上学期独立完成的 Java SE 练手项目，包含日常的知识点测试以及一个完整的控制台版学生管理系统。

## 🌟 核心项目：学生管理系统
*   **位置**：在 `src/com/studentsystem` 目录下（点击左侧目录可查看）。
*   **功能**：用户注册（含正则表达式校验）、登录验证、忘记密码，以及学生信息的增删改查。
*   **技术栈**：Java面向对象、集合框架（ArrayList, HashSet）、正则表达式。

## 📁 其他目录
其他文件夹为日常学习 Demo（如内部类、接口演示、泛型测试等）。
